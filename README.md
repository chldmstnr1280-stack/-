# SELLERY (Self Love Reset)

감정의 정원에서 성장하는 HSP를 위한 디지털 치료제

당신의 감정을 이해하고, 셀리와 함께 성장해요 💚

---

## 프로젝트 구조

```
sellery/
├── mobile/          # React Native 앱 (iOS/Android)
├── backend/         # Node.js API 서버
├── shared/          # 공유 타입 및 유틸리티
├── docs/            # 문서
└── old/             # 기존 프로토타입 백업
```

## 기술 스택

### Mobile (React Native)
- React Native 0.74+
- TypeScript
- Zustand (상태 관리)
- React Navigation
- Realm (로컬 DB)
- Lottie (애니메이션)

### Backend
- Node.js 20+
- Express
- MongoDB + Mongoose
- JWT 인증

---

## 시작하기

### Mobile 앱

```bash
cd mobile
npm install
npm run ios     # iOS
npm run android # Android
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## 핵심 기능

1. **7일 온보딩 미션** - 셀리와 함께하는 감정 여행
2. **감정 추적 & 게임화** - 매일 기록하며 셀리 성장
3. **주간 마음 체크인** - PHQ-9/GAD-7 기반 과학적 평가
4. **맞춤형 루틴** - 명상, 호흡법, 정원 산책
5. **정원 마켓** - 셀리 커스터마이징
