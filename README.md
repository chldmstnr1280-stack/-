# MELTING HAM (멜팅햄) — 웰니스를 즐겁게

목욕탕·사우나·찜질방 이용자를 위한 모바일 중심 웰니스 플랫폼 **인터랙티브 프로토타입**입니다.
시설 탐색 → 시설 비교 → 세신 예약 → 현장 대기 → 찜질방 혼잡도 확인 → 관리자 화면에서 상태 변경까지 전 과정을 체험할 수 있습니다.

> ⚠️ 모든 목욕탕·세신사·평점·수질·혼잡도 정보는 **시연용 가상 데이터**입니다. 실제 결제, 실제 예약 전송, 실제 수질 데이터 연동은 없습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 타입 체크 + 프로덕션 빌드 (dist/)
```

기술 스택: React 19 · TypeScript · Tailwind CSS 3 · Vite · React Router(HashRouter, 정적 호스팅 가능) · lucide-react

## 화면

| 경로 | 화면 |
|---|---|
| `#/` | 홈 (지역 선택, 추천 카테고리, 추천 목욕탕, 내 예약/대기 요약, 찜질방 혼잡도 요약) |
| `#/search` | 목욕탕 검색 (지역·시설·서비스·카테고리 필터, 세신 예약 가능, 수질검사 정보, 정렬) |
| `#/bath/:id` | 목욕탕 상세 (시설 소개, 위생·수질, 세신 서비스, 실시간 찜질방 혼잡도) |
| `#/book/:bathId` | 세신 예약 (세신사 → 서비스 → 달력·시간 → 확인 → 완료) |
| `#/reserve` | 세신 예약 탭 (예약 가능 시설, 내 대기표/예약) |
| `#/queue/:bathId` | 현장 대기 (번호 발급, 진행 상태, 순서 진행 바, 호출 응답, 취소, 새로고침) |
| `#/crowd/:bathId` | 찜질방 현황 (시설 전체 혼잡도, 시간대별 그래프, 찜질방별 인원) |
| `#/my` | 마이 (예약 내역·취소, 10분 전 알림 시뮬레이션, 즐겨찾기, 이용 기록, 운영 메뉴) |
| `#/notifications` | 웹앱 내부 알림 |
| `#/staff` | 세신사 관리 (일정표, 시작/완료, 휴식시간, 일일 한도, 예약 중단, 소요시간, 근무 요일, 현장 대기) |
| `#/admin` | 목욕탕 관리자 (대시보드, 대기·통합 일정표, 찜질방 입장/퇴장, 위생·수질, 시설 정보, 세신사 등록/배정) |
| `#/display/room/:roomId` · `#/display/rooms/:bathId` | 찜질방 입구 디스플레이 |
| `#/display/queue/:bathId` | 세신 대기 공용 디스플레이 (대기번호만 표시) |

데스크톱에서는 모바일 화면 옆에 **시연 가이드**(운영 화면 바로가기, 테스트 시나리오 A–E, 데모 초기화)가 표시됩니다. 모바일에서는 마이 탭 하단 “운영 · 시연 메뉴”에서 같은 기능을 쓸 수 있습니다.

## 데이터와 동기화

- 상태(예약, 대기번호, 즐겨찾기, 찜질방 인원, 관리자 변경 사항, 알림)는 `localStorage`(`meltingham:state`)에 저장되어 새로고침 후에도 유지됩니다.
- **같은 브라우저의 다른 탭**(관리자 화면, 입구 디스플레이)과는 `storage` 이벤트로 즉시 연동됩니다.
- 다른 기기·브라우저 간 실시간 동기화는 지원하지 않습니다 (향후 Supabase/Firebase 등 서버 도입 단계).
- 마이 탭 또는 시연 가이드의 “데모 데이터 초기화”로 처음 상태로 되돌릴 수 있습니다.

## 주요 규칙

- 혼잡도: 0~40% 여유 · 41~70% 보통 · 71~99% 혼잡 · 100%+ 매우 혼잡 (권장 인원은 프로토타입 설정값, 법정 수용 인원 아님). 인원은 음수 불가.
- 예약 슬롯: 세신사별로 관리되며 서비스 소요시간 기준으로 기존 예약·휴식시간과의 겹침, 휴무일, 예약 중단, 일일 한도를 검사합니다. 확정 시 최신 상태로 재검증해 중복 예약을 막습니다. 다른 고객 예약은 결정적 시뮬레이션으로 생성됩니다(11:20은 항상 마감).
- 현장 대기: 대기 중 → 곧 차례(앞 1명 이하) → 호출 중 → 서비스 진행 → 완료. 호출 후 30초 내 응답이 없으면 관리자 화면에 ‘미응답’ 표시, 재호출/순서 보류/복귀 가능, 순서 변경 내역 기록. 예상 대기시간 = 앞 순서 고객들의 서비스 소요시간 합.
- 수질 정보: 지자체 검사 + 증빙 제출 시에만 “지자체 검사 · 증빙 확인”, 그 외에는 “사업장 제공 정보”. 값이 없으면 ‘미확인’/‘정보 없음’. 물 교체 시간이 수질 안전을 보증하지 않는다는 안내를 함께 표시합니다.
