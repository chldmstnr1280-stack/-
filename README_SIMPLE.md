# 🚀 SELLERY 실행하기 (초간단 버전)

## Windows에서 실행하는 방법 (3단계만!)

### 1단계: 코드 받기
- GitHub에서 "Code" 버튼 클릭
- "Download ZIP" 클릭
- 다운로드한 ZIP 파일 압축 풀기

### 2단계: Node.js 설치 (이미 있다면 건너뛰기)
- https://nodejs.org/ 접속
- 왼쪽 초록 버튼 "LTS" 클릭해서 다운로드
- 설치 프로그램 실행 (다음, 다음, 완료)

### 3단계: 실행!
- 압축 푼 폴더에서 `web` 폴더 열기
- `start.bat` 파일 더블클릭!
- 끝! 브라우저가 자동으로 열립니다 🎉

## 문제 해결

### "Node.js를 찾을 수 없습니다" 에러가 나요
→ Node.js를 설치하세요 (위 2단계 참고)

### 브라우저가 자동으로 안 열려요
→ 수동으로 브라우저 열고 http://localhost:3000 입력

### 포트가 사용 중이라고 나와요
→ 다른 프로그램이 3000 포트를 쓰고 있습니다
→ 터미널에서 `netstat -ano | findstr :3000` 실행
→ 해당 프로그램 종료

---

## 종료하는 방법

- 실행 중인 검은 창(터미널)에서 `Ctrl + C` 누르기
- 또는 창 닫기
